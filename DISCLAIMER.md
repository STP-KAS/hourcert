# Disclaimer

**Experimental. Not advice. Testnet-10 only.**

hourcert lives on Kaspa Testnet-10. tKAS has no value. hourcert is not money, not a token, not a registry recognised by anyone, not an energy certificate scheme, not an oracle and not part of Kaspa core. There is no mainnet version and none is planned.

hourcert is a plain Argent app. It is not a KCC. Argent (argent-lang/argent `9a9f4b10`) is not yet released and not audited. Silverscript v1.0.0 is released. The build uses the argent-lang/kcc20-reference checkout only as a pinned toolchain; hourcert does not use KCC-20. Any of these can change, and if they do, this design may stop working.

Nothing here has had a security review. Treat the contract as a teaching sketch, not a vault for real money.

hourcert cannot see electricity, meters or hydrogen. A certificate is only as good as the meter key, the issuer and the auditor behind it. No certificate made here is a Guarantee of Origin, a REC, an I-REC, an EnergyTag Granular Certificate or a ZETA certificate, and none may be used for any claim. The drill used made-up facilities, hours and amounts.

This repository holds no key, no seed and no wallet. Never paste a seed anywhere for this.

Intentions are good; thought process is questionable. STP remains delusional. Si vis pacem, para bellum.
